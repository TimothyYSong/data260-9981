# AGENT.md — DATA 260 HW6

## Project Description
- Assist with local restaurant inspection analysis and explain findings using available evidence.

## Technology Stack
- Use Python, FastAPI, Pydantic, PyMongo, MongoDB, and Ollama with the local qwen3:8b model.

## Coding Conventions
- Use descriptive snake_case function names, type hints, and docstrings for new Python functions.
- Please use strict bullet-only code review.

## Testing Approach
- Test generated functions with valid and invalid inputs before accepting them.
- Verify API responses, HTTP status codes, and database persistence after implementation changes.

## Prohibited Actions
- Never fabricate restaurant inspection records, dates, violations, or statistics.
- Never expose credentials or delete existing database records without explicit authorization.
