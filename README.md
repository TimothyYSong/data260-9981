## Part 4 Questions

Why is prior conversation context resent with every turn?
Prior conversation context is resent with every turn, so the model can refer to previous history to help it with generating its responses.

How is a system prompt different from a user message? 
System prompts tell the model how to do something, while user messages tell the model what to do.

Why do input tokens grow over a conversation? 
Input tokens grow over a conversation because with each new message the history is resent too, so the token amount grows.

What eventually limits that growth? 
Usually, the model’s context window will limit the growth, because each model has a maximum number of tokens.
