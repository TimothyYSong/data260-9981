=== CONFIGURATION C: CONTEXT-ENGINEERED RAG ===
Gradient descent is described as a common optimization algorithm used to find the weights that minimize a cost function. It relies on the gradient, which is a vector of partial derivatives, to determine the direction in which the function decreases. The process involves three steps: (1) selecting a random starting point, (2) computing the gradient, and (3) taking a small step in the direction of the gradient. The update rule for weights is given by $ W_j^t := W_j^{t-1} - \alpha \frac{\partial J}{\partial W} $, where $ \alpha $ is the learning rate [Source 1].

=== CONFIGURATION C: CONTEXT-ENGINEERED RAG ===
Gradient descent is described across the lecture documents as an optimization algorithm used to minimize a cost function by iteratively adjusting model weights in the direction of the steepest descent, determined by the gradient. Key points include:  
1. **Basic Mechanism**: Gradient descent updates weights using the formula $ W_j^t := W_j^{t-1} - \alpha \frac{\partial J}{\partial W_j} $, where $ \alpha $ is the learning rate, and the gradient indicates the direction of maximum decrease [Source 1].  
2. **Variants**:  
   - **Batch Gradient Descent**: Computes gradients using the entire training dataset [Source 3].  
   - **Stochastic Gradient Descent (SGD)**: Uses gradients from a single training instance for updates [Source 3].  
   - **Momentum Update**: Enhances gradient descent by incorporating velocity ($ v = \beta v - \text{learning rate} \cdot dx $) to accelerate convergence [Source 2].  
3. **Implementation**: Tools like PyTorch’s Autograd automate gradient computation, enabling scalable optimization without manual calculus [Source 4][Source 5].  

These descriptions highlight gradient descent’s role as a foundational method, its variants for efficiency, and practical implementation via automatic differentiation.
