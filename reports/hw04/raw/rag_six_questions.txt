=== CONFIGURATION A: NO RAG ===
Gradient descent is an optimization algorithm used to minimize a function by iteratively adjusting its parameters in the direction opposite to the gradient of the function. Here's a structured explanation:

1. **Core Concept**:  
   Gradient descent finds the minimum of a cost function (e.g., error between predicted and actual values in machine learning) by moving parameters in the direction of the steepest descent, determined by the negative gradient.

2. **Mathematical Formulation**:  
   For a cost function $ J(\theta) $, the update rule is:  
   $$
   \theta_{\text{new}} = \theta_{\text{old}} - \alpha \nabla J(\theta_{\text{old}})
   $$  
   - $ \alpha $: Learning rate (controls step size).  
   - $ \nabla J(\theta) $: Gradient (vector of partial derivatives).

3. **Variants**:  
   - **Batch Gradient Descent**: Uses the entire dataset for each update (stable but computationally heavy).  
   - **Stochastic Gradient Descent (SGD)**: Uses a single data point (faster but noisier).  
   - **Mini-Batch Gradient Descent**: Uses a small random subset (balances speed and stability).  
   - **Momentum**: Adds a fraction of the previous update direction to accelerate convergence.  
   - **Adaptive Methods (e.g., Adam)**: Adjust learning rates dynamically based on parameter history.

4. **Key Considerations**:  
   - **Learning Rate**: Too high may overshoot the minimum; too low slows convergence.  
   - **Local Minima**: Non-convex functions may trap the algorithm, though convex problems have a single global minimum.  
   - **Applications**: Widely used in training models like linear regression, neural networks, and logistic regression.

In summary, gradient descent is a foundational technique for optimizing machine learning models by iteratively refining parameters to minimize error, with variations tailored to different computational and convergence needs.

=== CONFIGURATION B: BASIC RAG ===
Gradient descent is an optimization algorithm used to minimize a cost function by iteratively adjusting the model's parameters (weights) in the direction that reduces the function's value. Here's a concise breakdown:

1. **Core Concept**:  
   - The algorithm computes the gradient (vector of partial derivatives) of the cost function $ J(w) $ with respect to the parameters $ w $. This gradient indicates the direction of steepest ascent, so the update rule moves the parameters in the **opposite direction** (negative gradient) to minimize $ J(w) $.

2. **Update Rule**:  
   $$
   W_j^t = W_j^{t-1} - \alpha \frac{\partial J}{\partial W_j}
   $$  
   - $ W_j $: Parameter being updated.  
   - $ \alpha $: Learning rate (step size).  
   - $ \frac{\partial J}{\partial W_j} $: Partial derivative of the cost function with respect to $ W_j $.

3. **Key Steps**:  
   - **Step 0**: Start with random initial weights.  
   - **Step 1**: Compute the gradient of the cost function.  
   - **Step 2**: Adjust the weights by taking a small step in the direction of the negative gradient.

4. **Variants**:  
   - **Batch Gradient Descent**: Uses the entire training dataset to compute the gradient.  
   - **Stochastic Gradient Descent (SGD)**: Uses a single data point (or a small subset) for each update, introducing noise but faster convergence.  
   - **Mini-batch Gradient Descent**: A balance between batch and stochastic, using small random subsets of data.  

5. **Purpose**:  
   Gradient descent is fundamental in machine learning for training models by iteratively minimizing loss functions, enabling models to learn optimal parameters for tasks like regression and classification.

Gradient descent is an optimization algorithm used to find the weights that minimize a cost function by iteratively adjusting parameters in the direction of the negative gradient. The process involves:  
1. **Step 0**: Picking a random starting point.  
2. **Step 1**: Computing the gradient (vector of partial derivatives) to determine the direction of steepest descent.

Variants like **batch gradient descent** compute the gradient using the entire training dataset, while **stochastic gradient descent** uses a single data point at each iteration [Source 3].

=== CONFIGURATION A: NO RAG ===
**Batch Gradient Descent:**  
Batch gradient descent computes the gradient of the loss function using the entire training dataset. Specifically, it calculates the average gradient across all training examples. The gradient is given by:  
$$
\nabla J(\theta) = \frac{1}{N} \sum_{i=1}^N \nabla J_i(\theta)
$$  
where $ N $ is the number of training examples, and $ J_i(\theta) $ is the loss for the $ i $-th example. This ensures the update direction is based on the global average of the gradients, leading to stable convergence but potentially slow updates due to the large computational cost.

**Momentum Gradient Descent:**  
Momentum gradient descent introduces a **velocity** term to accelerate convergence by accumulating past gradients. The velocity $ v_t $ and parameter update equations are:  
1. **Velocity Update:**  
$$
v_t = \beta v_{t-1} + \eta \nabla J(\theta)
$$  
where $ \beta $ is the momentum hyperparameter (e.g., 0.9), $ \eta $ is the learning rate, and $ \nabla J(\theta) $ is the gradient computed via batch gradient descent.  
2. **Parameter Update:**  
$$
\theta_t = \theta_{t-1} - v_t
$$  
The velocity smooths the update direction by incorporating historical gradients, helping navigate flat regions and avoid local minima. This reduces oscillations and speeds up convergence compared to standard gradient descent.  

**Key Difference:**  
While batch gradient descent uses the full dataset's gradient, momentum adds a velocity term that exponentially weights past gradients, enabling faster and more stable optimization.

=== CONFIGURATION A: NO RAG ===
Momentum is a fundamental concept in physics that quantifies the motion of an object. It is defined as the product of an object's **mass** and its **velocity**. Mathematically, it is expressed as:  

$$
\text{Momentum} (\vec{p}) = m \cdot \vec{v}
$$  

Where:  
- $ m $ = mass of the object (in kilograms, kg),  
- $ \vec{v} $ = velocity of the object (in meters per second, m/s).  

### Key Characteristics:  
1. **Vector Quantity**: Momentum has both magnitude and direction, same as velocity.  
2. **Units**: The SI unit of momentum is **kilogram-meter per second (kg·m/s)**.  
3. **Dependence on Motion**: An object at rest has zero momentum, while a moving object has momentum proportional to its mass and speed.  

### Example:  
A truck moving at 20 m/s has a larger momentum than a bicycle moving at the same speed because its mass is much greater.  

Momentum is crucial in analyzing collisions and understanding how forces affect motion over time.
